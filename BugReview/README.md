# Bug Reviews

One file per hackathon day (a task, not a calendar date), named `Day X Bug Review.md`.
Run `/qodo-bug-review day N` to start a new day; with no day given it continues the latest file.
Written by the `qodo-bug-review` skill: root cause, solutions considered, chosen fix and its
biggest weakness, the red/green/refactor record, and the lesson added to `../LessonsLearned.md`.
